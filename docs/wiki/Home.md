# Dynamic Animation Framework SE
Dynamic Animation Framework SE (DAF) lets you trigger custom animation chains in Skyrim Special Edition when certain in‑game or menu events happen (pick up, drop, equip, open inventory, etc.).  
You add simple JSON files that say: “When event X happens, and the item / actor matches these filters, play these animations in this order.”

Other mods have also the option to register their custom events to DAF.

No Papyrus or coding required.
